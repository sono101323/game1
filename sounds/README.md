# 効果音について

このフォルダの効果音（`*.mp3`）は、npm パッケージ [uisfx](https://www.npmjs.com/package/uisfx)（バージョン 0.4.0）に含まれる音源から選び、ゲームでの用途に合わせて名前を付け直したものです。

uisfx の音源は CC0 1.0（パブリックドメイン）で提供されています。商用を含めて、許可なく複製・改変・再配布できます（ライセンス本文：`LICENSE-AUDIO.txt`）。

| ファイル | 元の音源 | 使う場面 |
|---|---|---|
| press.mp3 | arcade/press | ボタンを押したとき |
| ready-on.mp3 / ready-off.mp3 | arcade/toggle-on / toggle-off | 準備OK・取り消し |
| join.mp3 / leave.mp3 | arcade/connect / disconnect | ルームへの入室・退出 |
| chat-in.mp3 / chat-out.mp3 | arcade/receive / send | チャットの受信・送信 |
| power-lock.mp3 | arcade/lock | 強さを決めたとき |
| launch.mp3 | scifi/start | 打ち出したとき・試合開始 |
| hit-big.mp3 | mechanical/snap | 強い衝突 |
| ability.mp3 | arcade/bonus | アビリティを使ったとき |
| hyper.mp3 | scifi/level-up | ハイパー無敵 |
| ability-ready.mp3 | arcade/unlock | 自分のアビリティが使えるようになったとき |
| passive.mp3 | arcade/achievement | パッシブアビリティが発動したとき |
| ko.mp3 | arcade/reward | 相手を倒したとき（ハンター） |
| ringout.mp3 | arcade/drop | 場外 |
| spinout.mp3 | arcade/sleep | スピンアウト |
| win.mp3 / lose.mp3 | arcade/complete / error | 勝ち・負け |
