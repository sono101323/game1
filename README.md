# 文字ゴマ道場

入力した一文字の形から重さ・攻撃・持久・安定が決まり、3Dのすり鉢スタジアムでぶつけ合うブラウザゲームです。

- 遊ぶ: https://sono101323.github.io/game1/ （GitHub Pages を有効にしたあと）
- CPU 対戦（CPU は1〜3体）と、ルーム番号を使ったオンライン対戦（最大4人。PeerJS によるブラウザ間の直接通信）に対応しています。
- 対戦前にアビリティを1つ選び、対戦中にボタン（またはスペースキー）で使えます。ダッシュ・踏ん張り・衝撃波・スピンブースト・操縦はクールダウン制、回転チャージ・中央復帰・ハイパー無敵は1試合の回数制です。
- アクティブアビリティとは別に、自動で働くパッシブアビリティ（リスポーン・吸収回転・根性・重装・ゴム壁・ハンター・逆境）を1つ選べます。
- 文字は上下左右に倒したり、90度回したり、上下・左右に反転したりして形を変えられます（倒すと性能が変わります）。
- スタジアムの壁は対戦中に回転し、場外ポケットの位置も動きます。
- ビルド不要の単一ファイル（`index.html`）です。three.js と PeerJS は CDN から読み込みます。

## 効果音

`sounds/` の効果音は、npm パッケージ uisfx の CC0（パブリックドメイン）音源を使っています。詳しくは `sounds/README.md` を参照してください。画面右上の「音 ON／OFF」で切り替えられます。
