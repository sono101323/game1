# 文字ゴマ道場

入力した一文字の形から重さ・攻撃・持久・安定が決まり、3Dのすり鉢スタジアムでぶつけ合うブラウザゲームです。

- 遊ぶ: https://sono101323.github.io/game1/ （GitHub Pages を有効にしたあと）
- CPU 対戦（CPU は1〜3体）と、ルーム番号を使ったオンライン対戦（最大4人。PeerJS によるブラウザ間の直接通信）に対応しています。
- 対戦前にスキルを1つ選び、対戦中にボタン（またはスペースキー）で使えます。ダッシュ・踏ん張り・衝撃波はクールダウン制、回転チャージ・中央復帰・ハイパー無敵は1試合の回数制です。
- ビルド不要の単一ファイル（`index.html`）です。three.js と PeerJS は CDN から読み込みます。
